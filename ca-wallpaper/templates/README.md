# templates / 已验证模板

两个都是**用户在自己 iPhone 上确认过功能正常**的包，画布 390×844 @3x。

| 文件 | 原名 | 内容 | 外观 | 验证 |
|---|---|---|---|---|
| `template_A_lishiya_depth_ok.tendies` | 李诗雅修复景深 | 人物拼贴，Floating 9 个可见图层（大图为主），简单结构 | 单外观 | ✅ 景深 |
| `template_B_kumu_v10_all_ok.tendies` | 枯木逢春_景深_v10 | 一张压平树图 + ~790 个开花叶子图层与动画 + 源包 Background（纸色/夜空/月亮云） | **深浅色自适应**（Light/Dark 各 3 状态） | ✅ **用户确认全部功能可用**：景深 + 深色模式 + 叶子动态 |

## 怎么选
- **A**：`graft` 省略 `--template` 时的默认；结构最简单，适合任何"单外观 + 景深"的需求。
- **B**：需要**深浅色自适应 + 景深 + 保留大量装饰图层/动画**时用它当骨架（它证明这些可以同时存在）。
  用 B 当模板时，建议 `--keep-layers --appearance keep --background source`，让新壁纸沿用 B 的结构。
  注意：B 的深浅色状态里写的是"枯木逢春"的图层 id；换成别的素材时，应把素材的深色逻辑也一并带来（`--background source` + 源包自带 Light/Dark 状态），否则深色下只会换背景不会有别的变化。

## 使用前请注意
1. **先让用户在自己手机上单独导入模板，确认功能正常**，再拿它当骨架。不同机型/系统版本可能表现不同。
2. 只适用 **390×844** 画布。其它机型请让用户提供该机型上验证过的模板，不要硬缩放。
3. 模板里的画面（人物/树）是原作者的素材。graft 只借用结构、替换画面；若要公开分发，请移除模板或换成自己的素材。
4. 输出包里会带有模板的 UUID 与名称字段——这是正常的。
5. 说明：`tendies.py graft --keep-layers --background source --appearance keep` 的输出在结构上与 B 等价（文件数/体积/自检一致），
   但**被用户验证的是 B 这个文件本身**，工具重新生成的版本没有单独在真机上验证过。
